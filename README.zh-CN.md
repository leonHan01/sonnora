# 声屿 · Sonora

[English](README.md) | **简体中文**

一款使用 SwiftUI、AppKit 和 AVFoundation 编写的 macOS 原生音乐播放器。以深色界面与浅绿色点缀，集中管理本地音乐、歌单和播放统计；也支持连接兼容的音乐服务器，将下载的歌曲缓存到本机，供离线收听。

无第三方依赖。应用界面目前为简体中文。

## 功能

- **本地曲库**：导入歌曲或递归导入文件夹，也可拖入窗口，或通过 Finder 的「打开方式」导入；自动跳过重复文件路径。
- **播放控制**：播放、暂停、停止、进度拖动、音量和静音；支持顺序播放、列表循环、单曲循环和随机播放。
- **mini 播放器**：380 × 124 点固定内容尺寸，窗口可移动，展示封面和歌曲信息，提供播放控制、进度条与播放顺序菜单；恢复完整窗口时保留原来的大小和位置。
- **曲库整理**：浏览全部音乐、最近添加的 50 首歌曲、收藏及自定义歌单；支持新建、重命名、删除歌单，并通过「＋」快速添加歌曲。
- **歌手与统计**：歌手页面展示歌曲数量与播放次数；可按歌名、歌手、专辑或文件名搜索歌曲。歌曲支持按添加时间、名称、歌手或播放次数排序，歌手支持按名称、播放次数或歌曲数量排序。
- **播放队列**：查看待播歌曲，安排下一首，移除队列条目或清空待播。
- **歌曲信息**：自动读取标题、歌手、专辑、封面和时长；缺少标题标签时使用文件名，无封面时显示深灰色占位块。
- **定位当前歌曲**：点击「定位当前」、底部播放栏的封面或歌曲信息，或按 `⌘J`，即可滚动定位并高亮当前歌曲。
- **在线与离线收听**：浏览服务器歌曲，首次播放时下载；服务器不可用时继续使用本地和已缓存音乐。
- **我的电台**：点击侧栏「我的电台」，从服务器随机取一首歌播放。「换一首」和播放器的下一首按钮都能切歌，播完自动续播；有多首歌时避开上一首。离线时从本地及已缓存音乐中继续挑选，播放普通歌曲后退出电台。
- **系统集成**：支持 macOS「正在播放」信息、媒体控制命令和键盘快捷键；保存曲库与播放状态，重新打开后保持暂停。

支持的文件扩展名：**MP3、M4A、AAC、WAV、AIF、AIFF、CAF、FLAC**。实际编码支持以 macOS 解码能力为准。

## 环境要求

- **macOS 14.0 或更高版本**。
- 本文所述预编译版本面向 **Apple Silicon**；源码支持选择 `arm64` 或 `x86_64` 构建，Intel 版本尚未在 Intel 真机验证。
- 从源码构建需要安装 Xcode 或 Apple Command Line Tools，并使用 **Swift 6.0 或更高版本**。

## 安装

如果已有打包好的 DMG，打开后将 **声屿.app** 拖入「Applications」文件夹。升级时先退出旧版，再替换应用。曲库和歌单保存在应用包之外。

当前构建采用本地临时签名，尚未经过 Apple 开发者证书签名和公证。若 macOS 阻止打开，可在「系统设置 → 隐私与安全性」中允许本次打开。

也可以按照[从源码构建](#从源码构建)生成应用。

## 快速开始

### 本地音乐

1. 点击「添加我的音乐」或按 `⌘O`，选择歌曲或文件夹，也可直接拖入窗口。
2. 双击歌曲开始播放；单击仅选中歌曲，不会自动滚动列表。
3. 点击红心收藏，点击「＋」加入歌单；右键菜单提供更多操作，包括在 Finder 中显示文件和从曲库移除。
4. 按 `⌥⌘M` 在完整播放器与 mini 播放器之间切换。

本地音乐始终保留在原始路径：导入不会复制文件，从曲库移除也不会删除原文件。移动音乐文件后，请移除失效条目并重新导入。

关闭窗口后仍可在后台继续播放，使用 `⌘Q` 退出应用。

### 服务器连接

在线模式默认启用，并预设服务器地址。可以更换服务器，也可以关闭在线模式，仅使用本地音乐：

1. 从应用菜单打开「服务器连接…」，或点击侧栏底部的在线 / 离线状态。
2. 填写服务器的 HTTPS 根地址，以及服务器要求的访问令牌。本机开发也允许使用 `localhost`、`127.0.0.1` 或 `::1` 的 HTTP 地址。
3. 点击「保存并连接」。令牌留空会继续使用该服务器已保存的令牌；勾选清除选项可移除已保存令牌。

启用在线模式后，应用每 30 秒刷新连接和歌曲列表。连接或下载失败时，曲库切换为本地和已缓存音乐。尚未缓存的服务器歌曲需要联网，首次播放会等待下载完成；下载内容会校验文件大小和 SHA-256 摘要，再保存到缓存。

访问令牌按服务器分别保存在 macOS 钥匙串中。「打开歌曲管理」会在浏览器中打开服务器的 `/music.html` 页面。

在线功能需要兼容的服务器，本仓库不包含服务端实现。客户端使用以下接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/music/tracks` | 返回歌曲元数据的 JSON 数组。 |
| `GET /api/music/tracks/{id}/audio` | 下载歌曲音频文件。 |
| `GET /api/music/tracks/radio?exclude=<UUID>` | 随机获取一首可播放歌曲，尽量避开上一首；电台为空返回 204。 |
| `/music.html` | 浏览器中的歌曲管理页面。 |

元数据字段包括 `id`（UUID）、`title`、`artist`、`album`、`duration`（秒）、`extension`、`sha256`、`size`（字节）和 `uploadedAt`（ISO 8601）。客户端接受支持的小写扩展名、小写 SHA-256 摘要，以及不超过 128 MiB 的文件。配置令牌后，API 请求携带 `Authorization: Bearer <token>`。具体约定见 [OnlineLibrary.swift](Sources/Sonora/OnlineLibrary.swift)。

## 从源码构建

在项目根目录运行：

```sh
bash Scripts/build.sh
```

脚本为当前机器架构编译发布版本，生成图标，将应用打包到 `dist/声屿.app`，并完成临时签名及签名校验。构建过程不会启动应用。

同时生成并校验 `dist/声屿-Sonora-<版本号>.dmg`；新包成功后仅保留最新的声屿 DMG。已有应用无需重新编译，可直接运行 `bash Scripts/package-dmg.sh` 打包。

也可以明确指定目标架构：

```sh
# Apple Silicon
bash Scripts/build.sh arm64

# Intel
bash Scripts/build.sh x86_64
```

开发时可使用 Xcode 打开 `Package.swift`。构建脚本不依赖完整 Xcode，默认将编译缓存保存在项目的 `.build/` 目录。

| 环境变量 | 用途 |
| --- | --- |
| `SONORA_BUILD_ROOT` | 修改各脚本使用的构建及编译缓存目录。 |
| `SONORA_APP_OUTPUT` | 修改 `Scripts/build.sh` 生成的应用包路径。 |
| `SONORA_LIBRARY_PATH` | 开发时启动应用可指定独立的曲库 JSON 路径；连接设置和音频缓存放在该文件旁。 |

## 测试与验证

使用仓库中的 Shell 脚本编译并运行测试程序：

| 命令 | 检查范围 |
| --- | --- |
| `bash Scripts/test.sh` | 队列规则、播放状态、保存恢复、导入与解码、歌单、当前歌曲定位、歌手统计、缓存，以及进度 / 音量 / 选中状态的独立更新。 |
| `bash Scripts/test-online.sh` | 模拟服务器认证、超时回退与恢复、稳定标识、旧数据兼容、离线缓存及下载完整性；不创建窗口或播放声音。 |
| `bash Scripts/test-performance.sh` | 5,000 首模拟歌曲的页面数据读取；每项预热后连续刷新 8 次，总耗时预算为 100 毫秒。 |
| `bash Scripts/test-rendering.sh` | 歌曲行视图值、更新范围、布局断点、窗口约束逻辑，以及封面后台加载、缓存和取消。 |
| `bash Scripts/test-mini-window.sh` | 使用离屏测试窗口检查 mini / 完整窗口约束与恢复。 |
| `bash Scripts/test-mini-window-scene.sh` | 使用透明、不可交互的测试窗口检查生产 SwiftUI 窗口配置。 |

核心测试使用自行生成的 12 秒静音 MP3，不播放声音，但解码检查需要访问 macOS 音频服务。页面性能和视图更新检查不会创建窗口或播放声音。mini 窗口检查会创建测试窗口，需要可用的 macOS 窗口服务。测试使用独立曲库路径。

页面数据基准与视图值检查不代表真实渲染帧率。历史验证结果及其适用范围记录在 [VALIDATION.md](VALIDATION.md)。

## 数据与播放次数

默认数据目录：

```text
~/Library/Application Support/Sonora/
├── library.json          # 歌曲索引、歌单、收藏、播放次数与播放状态
├── online-settings.json  # 服务器地址与在线模式设置
└── online-audio/         # 已下载的服务器音频
```

曲库索引保存文件路径、标签、缩略封面和播放状态，不嵌入原始音频。访问令牌保存在钥匙串。索引无法解析时，应用会先尝试保留恢复副本，再允许保存新曲库。

每次成功开始新一轮歌曲播放计一次；暂停后继续和拖动进度不重复计数，重新选播、停止后播放及循环重播会累计。引入统计功能前的旧曲库初始次数为 0。歌手次数为当前可用曲库中该歌手歌曲的次数之和，按完整歌手标签分组，忽略大小写和首尾空白；合作歌手标签保留为一个条目。

本地播放无需服务器。启用在线模式后，会向配置的服务器请求歌曲列表和音频；导入本地文件不会上传音乐。应用没有遥测或在线歌词功能。
