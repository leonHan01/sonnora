# 声屿 Android

原生 Android 音乐客户端，使用 Java、Android View、MediaPlayer 和 MediaSession，无生产运行时第三方依赖。支持 Android 8.0（API 26）及更高版本，APK 不含特定 CPU 架构的原生库。

## 使用

1. 安装 `dist/声屿-Sonora-Android-1.1.1.apk`。
2. 在「设置」中填写原有访问令牌，服务器默认 `https://121.40.254.112`，点击「保存并连接」。APK 不包含生产令牌。
3. 点击歌曲播放，或进入「电台」随机收听。服务端无歌曲时，先通过「打开服务端歌曲管理」上传。

- 在线列表、在线歌单、电台和音频下载全部使用 `Authorization: Bearer <token>`。拒绝跟随 HTTP 重定向，HTTPS 使用系统证书校验。令牌按服务器分别使用 Android Keystore 的 AES-GCM 密钥加密保存，不进入曲库 JSON、URL 或通知；禁用系统云备份及设备数据迁移。
- 在线歌曲首次播放前完整下载，验证字节数及 SHA-256 后原子保存。缓存位于应用私有文件目录，重启保留；「设置 → 清理服务器歌曲缓存」可清理，导入的本地音乐不会删除。
- 连接失败后使用本地及缓存歌曲。前台每 30 秒重新连接；后台电台在下一首时适时重试。离线手动换歌直接选择本机歌曲，有多首时避免连续重复。
- 「歌单 → 在线歌单」显示服务端共享歌单，点击后可逐首播放或播放整张歌单，按服务端顺序建立队列。服务端管理页可拖拽排序，客户端刷新后重新播放歌单即使用新顺序；「播放歌单」会退出此前的随机模式。列表随曲库每 30 秒刷新，重启和断网后保留已加载的歌单；离线时只播放已缓存歌曲。服务端管理页支持创建、重命名、上传入单和批量加歌。
- 「我的喜欢」及歌单保存在本机，支持新建、重命名、删除、加入和移除歌曲，更新在线列表时保留收藏、播放次数及歌单引用。尚未缓存的在线歌曲在离线列表中隐藏，重新连接后恢复。
- 导入使用系统文件选择器，可多选；复制到应用私有目录并读取音频标签、封面和时长，不需要授予整机音乐目录权限。单首最多 128 MB，实际格式和编码支持取决于 Android 系统。
- 播放由媒体前台服务管理，切换页面或锁屏保持播放；支持通知栏及系统媒体控制、耳机断开暂停、音频焦点、进度拖动，以及顺序 / 列表循环 / 单曲循环 / 随机播放。重新打开应用保持暂停。

收藏、本地歌单和缓存为设备本地数据，卸载或清除应用数据会移除它们。正常覆盖安装升级时保留；服务器删除歌曲不会主动删除本机已缓存的音频。

## 构建

需要 JDK 17+、Android SDK Platform 35、Build Tools 35.0.0 和 Gradle 8.11.1。已包含 Gradle Wrapper，Android Studio 可直接打开此目录。

在仓库根目录：

```sh
bash Scripts/build-android.sh
bash Scripts/test-android-core.sh
```

初次构建会在忽略的 `.android-build/keys/sonora.jks` 生成本地签名文件。保留该文件用于后续覆盖升级，不要提交密钥或将真实访问令牌写入源码。脚本运行 Release 构建、Lint 和 APK 签名校验，并仅保留最新版 Android APK；已有 macOS DMG 不受影响。

可通过 `ANDROID_HOME` 指定 SDK，`SONORA_GRADLE_BIN` 指定 Gradle 可执行文件。依赖准备完成后可以 `bash Scripts/build-android.sh --offline` 构建。

无设备的 Android 测试：

```sh
cd android
./gradlew testDebugUnitTest
```

Robolectric 测试在 JVM 中模拟 Android 15，验证导航、服务初始化、收藏及歌单保存、缓存清理、取消待播，以及本机 HTTP 服务的认证 / 电台 / 下载 / 重定向拒绝。不启动模拟器、游戏或真实音频。测试依赖不打入 APK。

Gradle 插件和 SDK 组合参见 [Android 官方兼容表](https://developer.android.com/build/releases/agp-8-7-0-release-notes)；凭据存储遵循 [Android Keystore](https://developer.android.com/privacy-and-security/keystore) 的密钥使用方式。

## 上传、删除与来源

歌曲的更多菜单可一键上传云端，本地歌单详情及管理菜单可上传整张歌单并保留顺序。上传使用已有访问令牌；相同音频复用，失败后可再次操作继续。硬盘和云朵图标表示本地可播放副本及云端副本，两者都有时同时显示。

歌曲行垃圾桶按钮在确认后删除云端歌曲和对应缓存，或仅删除应用内导入副本，手机中的原始来源文件保留。设置中的清缓存会等待下载写入停止再清理音频与封面，收藏、歌单与凭据保留。客户端成功刷新完整曲库后，同步清理服务端已删除歌曲的缓存；离线设备恢复连接后同步。

在线歌曲可以边读取边播放；应用继续在后台下载并校验完整文件，校验成功后可离线收听。切歌或暂停不会立即取消已开始的后台缓存；停止服务、清空缓存或删除歌曲会取消相关任务。数据分段请求与完整下载均使用服务器令牌，并拒绝重定向。

在「音乐」页面点击「检测无效歌曲」会后台检查应用内导入的本地副本，自动移除确认缺失、内容校验失败或没有音轨的歌曲，并更新本地歌单和播放队列。带云端副本的歌曲保留云端记录、收藏及歌单引用；手机中导入前的原始文件不受影响。无法读取的文件会跳过，云端歌曲不会因离线而移除。
